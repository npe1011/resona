# 1. インストールと実行
単一ファイルで動きますので、resona.exeを適当な場所に置くだけです。実行時にユーザディレクトリ下に、`.resona` というディレクトリを作成しそこに一部設定ファイルを出力します。レジストリ等には干渉しません。

# 2. 対応形式
JEOLのJDF形式およびBrukerの形式に対応しています。
- **JEOLについても一部のマシンのデータでのみテストしています。**
- **JEOLのデータは未解析のファイルのみ読み込ます。解析したデータはちゃんと読めません。**
- **現状Brukerのデータはほとんどテストできていません（手元にデータがあまりありません）。**

# 3. 解析可能なデータ
一般的な一次元NMRを解析できます。二次元NMRは対応していません。
- **JEOLの軽溶媒NMRなどは処理が特殊なので対応していません。**
- **多核NMRの対応は現状はテストがあまりおこなえてません。**

# 4. 解析手順概要
ファイルを読み込むと前処理とフーリエ変換の設定画面がでるので、適宜Window関数やZero Fillingを設定し実行し、その後必要に応じて、位相補正・ベースライン補正・化学シフトのリファレンスセット・ピークピック・積分・拡大図の設定・カップリングの解析・印刷等をおこないます。それぞれ

# 5. 操作の概要
画面上部のツールバーで解析モードを切り替えながら順に実行します。おおよそ左から順にやればOKに並んでいます。画面の拡大や縮小はその下のZoomツールバーなどでおこないます。

# 6. 画面の拡大や縮小操作

## 6.1. Zoomツールバー
- X-Y: 矩形選択した部分を拡大します。
- X: 横軸方向の範囲を選択して拡大します。
- Y: 縦軸方向の範囲を選択して拡大します。
- Reset: 拡大をリセットします（履歴も消えます）

## 6.2. マウスやキーボード操作
- 矢印上下： Y-scaleを上下させます。画面右上の Y-Scale ToolバーのMax連動しています。
- Shift+矢印上下： Y-scale (負側)を上下させます。画面右上の Y-Scale ToolバーのMin連動しています。
- 矢印左右： 表示範囲を横にスクロールします。Shiftを押しながらやると少し大きく動きます。（**現状は範囲外にいくときがありますがあとで直します**)
- マウスのホイール： Y-scaleを上下させます。
- (Zoomモードのみ) ダブルクリック：拡大・縮小を一つ戻します。
- Home/back space: 拡大をリセットします。

## 6.3 キーボードによる一次的なZoomモードへの変更
- 他のモード（積分など）の操作中でも下記のボタンを押している間はZoomモードが優先します。拡大を変更しながら積分等をおこなうときに便利です。
- Z: 矩形 (X+Y)
- X: 横軸方向 (X)
- S: 縦軸方向 (Y)

## 6.4. Y-scaleに関して
Y-scaleは表示の倍率ではなく、Y軸の表示範囲倍率を調整しています。そのため完全にはベースラインが固定はされません。Maxで正方向、Minで負方向の表示を調整します。

# 7. 解析全般に関すること

## 7.1. Sensitivity
画面右上で自動検出の際の感度を切り替えられます（三段階）。高くすると検出するピーク、積分等が増えます。

## 7.2. 解析のUndo/Redo
Editメニューから、または Ctrl+Z (undo) や Ctrl+Y (Redo) でほとんどの解析操作を取り消せます。

# 8. フーリエ変換とその設定 (Re-FT)
Re-FTボタンを押すとフーリエ変換からやり直すことができます。

## 8.1. Window Function
現状は一般的なExpとGauss型のみを実装しています（他に使うものがあれば実装します）。
とりあえずの解析ではExpでLB(いわゆるブロードニングファクター）を適宜設定するのでいいと思います。

## 8.2. Zero Filling
1xはZero Fillingをおこないません。2x、4x ...は、元のデータ点をN倍するようにZero Fillingをおこないます。値が大きすぎると処理が重くなります（通常は2x～4x程度が妥当）。対応するデジタル分解能がその下に表示されるので参考にしてください。

## 8.3. Remove Digital Filter
通常はオンにしないとスペクトルがおかしくなりますのでオンにしておいてください。これは特にJEOLのデータでは機種依存の可能性がある処理で、テストしたデータの範囲では機能していますが、機種が大きく変わるとわかりません。

# 9. 位相補正（Phase）

## 9.1. 自動補正 (Auto)
Autoをおしてください。通常はFT実行時に自動で適用されています。

## 9.2. 手動補正 (P0 & P1)
P0、P1を適宜調整して位相をあわせてください。細かい調整は</>ボタンのほうがやりやすいと思います。
**現状はピボット位置が中央に固定されていて、微妙にうまくありませんが、これは修正する予定です**

# 10. ベースライン補正 (Baseline)
airPLS法またはPolynominal法で補正ができます。パラメータは通常はデフォルトでいいと思いますが、必要に応じて調整してください。きれいなスペクトルのときは必ずしも補正しなくても十分だと思います。
Clearを押すと補正無しに戻します。

# 11. 化学シフトの補正（Reference）
化学シフトの基準値と基準ピークを選んで補正します。基準値は溶媒やTMSの数値を選ぶか手動で入力します。
補正すると補正した基準値と基準位置が赤く表示されます。

## 11.1. 自動補正 (Auto)
Autoを押すと基準値の近くのピークを自動で探して補正をかけます。通常のスペクトルで溶媒ピーク等が十分大きいときはこれで大丈夫だと思います。

## 11.2. 手動補正 (Set)
Setボタンを押してピークを選択します。ドラッグした範囲で最も大きいピークが採用されます。

# 12. ピークピック (Peak Pick)

## 12.1. 自動ピック (Auto)
Autoをおしてください。ノイズレベルとSensitivityから閾値が計算されそれよりも大きいピークを検出します。

## 12.2. 半自動ピック (Threashold & Pick)
Threasholdボタンを押して閾値を調整してからPickボタンを押してください。

## 12.3. 手動ピック (Add & Delete)
Addボタンを押してドラッグすると、範囲内の大きいピークを1つ検出します。Deleteボタンを押してドラッグすると、範囲内の全てのピークを削除します。

## 12.4. ピークピックの全削除 (Clear)
Clearを押すと全てのピークピックを削除します。


# 13. 積分 (Integrate)

## 13.1. 自動積分 (Auto)
Autoを押すと適宜ピークを検出して積分します。そこまできれいには拾えないので、後述する手動と合わせて手直しするか、はじめから手動でやることが推奨されます。

## 13.2. 積分の追加 (Add)
Addを押して横方向に積分したい範囲をドラッグしてください。

## 13.3. 積分の編集 (Edit)
- ベースラインの青丸を動かすと積分のベースラインを動かせます。
- 積分曲線の上端をドラッグすると大きさ（Scale）を変更できます。これはScaleの数値を編集しても同じです。
- 積分曲線の下部～中央をドラッグすると積分曲線の位置（高さ）を調節できます。

## 13.4. 積分の分割 (Split)
Splitを選択すると青い縦線が表示され、クリックするとそこで積分を分割します。

## 13.5. 積分の削除 (Delelte)
クリックした位置またはドラッグした範囲の積分を全て削除します。

## 13.6. 積分基準値の変更（Set)
隣のボックスに数値を入力し、Setを押してから積分曲線をクリックすると、そこの積分値をその値に変更します。

## 13.7. 積分の全削除 (Clear)
既存の全ての積分を削除します。

# 14. 拡大図の作成（Multiview）

## 14.1. 倍率 (Ratio)
この数値はAddやAutoで作成する際の大きさに反映されます。

## 14.2. 自動整列 (Auto Align)
これをオンにしておくと拡大図を追加した際に高さや位置を自動的に調整します（後述するAdjust-YとAlignが自動実行される仕様です）。

## 14.3. 拡大図の追加と編集 (Add & Edit)
- スペクトル付近で横方向にドラッグするとその範囲の拡大図を追加します。
- 拡大図をドラッグすると移動できます。Shiftを押しながらドラッグすると水平・鉛直方向に移動します。
- 複数選択した上でドラッグすると全て同時に移動できます。Shift移動もできます。
- 拡大図の枠をドラッグすると大きさを変更できます。Shiftを押しながらドラッグすると縦横比を維持したまま大きさを変更できます。
- 拡大図をダブルクリックすると拡大図のY-Scaleを調整できます。
- 拡大図を選択してDeleteキーを押すと削除できます。

## 14.5. 拡大図の削除 (Delete)
拡大図をクリックすると削除します。

## 14.6. 拡大図の高さを揃える（Adjust-Y）
Adjust-Yを押すと全ての拡大図の高さを同じにします。このときもっとも左上にあるものに揃えます。

## 14.7. 拡大図の整列 (Align)
全ての拡大図を自動整列します。左上から順に、入り切らないときは複数段に整列します。

## 14.8. 拡大図を横一列に整列 (1-Row)
全ての拡大図が横一列になるように大きさを自動調整した上で自動整列します。

## 14.9. 拡大図の全削除 (Clear)
全ての拡大図を削除します。


# 15. カップリング解析 (J Coupling)
これを実行する前にピークピックが必要です。また1Hの場合は積分も先にとっておくと良いです。**比較的単純な処理のため複雑なパターンでは正確に解析できないと思います。またルーフが強いときの重心位置の算出は怪しいかもしれません。**

## 15.1. Allow Non-Integer
核の数は積分値に基づいて算出され整数値に丸められますが、これをオンにしておくと小数のまま出力します（異性体等の混合物の記述を想定した機能です）。

## 15.2. カップリング解析の追加 (Add)
範囲を選択するとその部分のピークからカップリングパターンとJ値の候補が出力されます。後ろに誤差値（Hz単位）も出力されるので、適切なものを選択してください。multipletとする場合は一番下を選択してください（化学シフト範囲はピークトップ範囲ではなく、選択した範囲になっています）。Add to Resultsをクリックすると画面右下のカップリングテーブルに追加されます。

##  15.3. カップリング解析の削除 
Clearを押すと全て削除します。またカップリングテーブルから個別の削除もできます。


# 16. 表示設定 (Display)
主に印刷やExport用に見た目を整えるための項目です。

## 16.1. 表示範囲 (X-Axis & Y-Axis)
スペクトルの表示範囲を数値で入力できます。印刷やPDF出力用に表示範囲を揃えるのに使えます。

## 16.2. 目盛りや数値の設定 (x-Axis Ticks & Precision)
化学シフト目盛りの振り方やピークピック、積分値の表示桁数を設定できます。**目盛りの設定は拡大図には反映されません。**

# 17. 印刷とエクスポート (Print)

# 17.1. 印刷
印刷するアイテムをチェックしてPrintを押すと印刷できます。Export SVGを押すとSVG (ベクター画像)として保存できます。PDFが必要なときはPDF仮想プリンタを利用してください。

# 17.2. 印刷設定 (Print Settings)
印刷、エクスポート時の色や線の太さ等を変更できます。この設定は保存されて次回起動時にも反映されるほか、設定ファイルのExport/Importもできます。
